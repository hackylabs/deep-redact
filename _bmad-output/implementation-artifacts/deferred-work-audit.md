## Deferred from: Story 8.2 design discussion (2026-05-31)

- **"Safe output" vs O(P) for non-configured positions — unresolved design decision.** The rule-driven engine (Story 8.2) never visits non-configured positions. Two consequences flow from that, only one of which is a hard failure:
  - **(A) The throw.** A non-configured circular reference is preserved raw by identity, so serialising it throws. This is **not** limited to a downstream consumer's `JSON.stringify` — Deep Redact's **own** `serialise: true` path is `JSON.stringify` (`src/core/create-redactor.ts:12-14`, applied at `:36`), and `serialise: true` does **not** disqualify a config from `pathDrivenOnly` (`src/core/compiler/compile-redactor-plan.ts:336-342`). So `deepRedact({ paths: [...], serialise: true })` over a payload with a non-configured cycle now **throws inside the library**, where the old general traversal returned a clean serialised string with a circular marker. Behaviour change: "works" → `TypeError`.
  - **(B) The behaviour.** Non-configured transformable runtime values (`Date`, `BigInt`, `Map`, `Set`, `Error`, `RegExp`, `URL`) and raw cycles appear **unchanged** in structured output. This is the **intentional, documented, test-pinned** Epic 8 decision (`epics.md §Epic 8 "Key design decision"`; `docs/architecture/rule-driven-traversal.md`; Story 8.1's two `// Activated by Story 8.2` contract tests assert exactly this).
- **Candidate fixes considered:**
  - **Cheap, contract-preserving (fixes A only):** replace vanilla `JSON.stringify` at the serialise boundary with a cycle-safe serialiser (seen-set replacer emitting the circular marker). O(output) — no extra traversal, O(P) preserved, structured output unchanged (Epic 8 contract honoured). Removes both the library throw and the documented downstream throw.
  - **Holistic, contract-reversing (fixes A and B — proposed by Ben):** keep rule-driven redaction (O(P)) but add a second pass that **traverses everything except already-redacted subtrees** (redacted/copied identities tracked in a `WeakMap`, discarded on completion), neutralising cycles and transforming non-configured runtime values in the remainder. Mechanism is correct and leak-free, but: it is **O(N − redacted-subtrees) ≈ O(N)** for the targeted small-config/large-payload case Epic 8 optimises for; it **reverses the Epic 8 key design decision**; it would **flip Story 8.1's two contract tests** back to the old behaviour; and it puts the **≤60 % benchmark gate at risk** (current `path-based-single-object-node24` is already ~123 % overhead with the fast lane, and 8.2 must bring it *down* to ≤60 — a full safety walk moves the wrong way). Adopting it is a **`correct-course` on Epic 8**, not a fix inside Story 8.2.
- **Decision (2026-05-31):** **Deferred.** Story 8.2 ships the documented behaviour change as currently specified — it does **not** add a serialiser fix or a safety traversal, and its Dev Notes carry the caveat forward. Revisit before public release to choose between the cheap serialiser fix (A only) and the holistic WeakMap traversal (A + B, via correct-course). If the holistic route is chosen, measure the real overhead of the WeakMap pass against the ≤60 % gate before committing.
