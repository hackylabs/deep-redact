Not a correctness issue; a future eligibility refinement could exclude configs where the delegation rate is near 100%.

## Deferred from: code review of 8-3-move-transformer-and-circular-handling-into-a-serialise-only-output-adapter (2026-05-31)

- **[Open] Cross-branch alias leaks an unconfigured-path value under exact-path config** — With `paths: ['a.secret']` and `{a, b:{ref:a}}`, both structured output and `serialise: true` still emit `b.ref.secret` raw. `serialise: true` now deliberately uses the general traversal, but alias replay still stores and replays raw snapshots under the later path. Revisit if/when alias-aware redaction is in scope.
- **[Open] Root array/Set/Map self-cycle circular-marker `path` semantics inconsistency** — Bare-root Set/Map self-cycles express the marker `path` relative to the transformed shape (`value.0` / `value.me`), while the root array case reports the direct index path (`0`). Output remains valid JSON; cosmetic/contract semantics only.
- **[Open] Plain-object getters are read twice under `serialise: true`** — Once in the phase-1 redaction traversal and again during the phase-2 safe-graph build (`serialise-output.ts`). Side-effecting or non-idempotent getters observe double evaluation; validation on 2026-06-05 reproduced a getter count of `2`. Document or memoise if it becomes a problem.
- **[Partially addressed] `serialise: true` returns `undefined` (not a string) for root non-JSON values** — Root symbol/function values now serialise to `"[UNSUPPORTED]"`; root `undefined` still returns `undefined`, matching native `JSON.stringify` semantics but preserving the remaining "not always a string" contract wrinkle.
- **[Partially addressed] Per-constructor custom transformers for arbitrary non-built-in types are not dispatched** — Unsupported `transformers.byConstructor` buckets are now rejected during validation, so arbitrary constructor keys are no longer silently accepted. First-class custom-constructor dispatch is still not supported: `resolveTransformedValue` only dispatches for the six built-in constructors (`Date`/`Error`/`Map`/`RegExp`/`Set`/`URL`) plus `bigint`; arbitrary class instances can still be handled only through `fallback` transformers.
